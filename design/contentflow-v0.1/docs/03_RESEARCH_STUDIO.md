# 03 — Research, evidence, editorial studio

## 1. Collection and normalization

Sources are adapters, not a generic unrestricted web scraper. P0 manual text/file/CSV/JSON/RSS fixture. P1 approved RSS, official APIs (GitHub releases, public data, Naver search/trends, Crossref/OpenAlex, own platform data), HTTP fetch and Trafilatura for allowed content; Playwright only for authorized access without evasion. P2 custom provider adapters. Do not scrape private accounts, copyrighted video captions, or paywalls. Respect source terms, robots where applicable, rate limits, access scope, content-size/time limits. Robots permission is not copyright permission. Respect deletion and refresh; source-specific rights registry decides whether raw text may be persisted or shared with LLM.

Pipeline: discover → canonicalize URL (preserve query with semantic meaning; drop only known tracking parameters) → access decision → fetch → MIME sniff, max bytes and archive expansion guard → normalize → language/timezone/date → dedup exact then near → candidate. Store retrieval timestamp distinct from publication and event date, publisher/author, canonical URL, revision/hash, extraction version, factual locator (page/section/line/timecode), source independence group, rights scope and expiry. Extracted text is untrusted data; instruction-like strings never grant tools, override budget or authorize posting. Keep provenance to source. Fetch redirect/DNS recheck; reject private/loopback/link-local addresses and dangerous schemes for external collector. Retry bounded. For scanned/mixed PDFs expose partial extraction and page coverage; do not label incomplete as complete. OCR optional only with consent and policy; Engram/MarkItDown adapter supplies coverage and tool version.

Dedup: exact hash; normalized URL and content checksum; similarity threshold as candidate review not automatic truth. Syndicated reports in same independence group do not count as corroboration. Handle updated articles and retractions with new revision, dependent claim invalidation and affected-publication queue. Source deletion/expiry must not silently become permission to republish cached material.

## 2. Claims and evidence

Evidence reference = source ID/revision + locator + allowed excerpt or reference + observed timestamp. Claims types `FACT, CALCULATION, INFERENCE, OPINION, FICTION, QUOTE`. States `UNVERIFIED, SUPPORTED, CONTESTED, STALE, REJECTED`. Claim verification requires at least one adequate primary source or two independent credible secondary sources for material ordinary claims as editorial default, not universal fact rule; high-stakes uses expert review, primary evidence and uncertainty. A single official announcement can establish that the issuer announced it, not validate performance claims. Calculations store input values, units, as-of dates, formula and deterministic recomputation; distinguish nominal/real, currencies, denominators. Inferences mark assumptions; quotes require exact source, permitted use, attribution; fiction labels clearly; opinions must not assert unverified facts. LLM confidence is not factual verification. Conflicts documented rather than averaging. Material unsupported, expired or contradictory claims block production or require explicit revision omitting/qualifying them.

## 3. Topic scoring and editorial choices

Candidate ranking configurable: demand 20, freshness 10, credibility 15, original value 20, revenue fit 20, media suitability 15. Each component 0..5 with evidence and reason; weighted normalized score 0..100. Missing evidence is unknown, not guessed; rank with known-score coverage and prohibit auto-select if critical missing. Default candidate >=80 with sufficient coverage, 65–79 backlog, lower reject or manual review. Compliance block overrides score. Don't optimize only trending volume; measure niche audience fit and portfolio overlap. Experiments define hypothesis, target, format, CTA, success/failure criteria and observation window before publication; no manipulative title/engagement.

Brief: intended audience/problem, angle, source list, claims, contradictions, original analysis, allowed asset plan, CTA and disclosure, risk classification, target duration/language, revision. Original value can be own benchmark, calculation, worked example, demonstration, visual interpretation, critique or original narrative; must be material and reviewed. No article-to-speech-only workflow for monetized channels. No automatic translation-only duplication across channels. Variant has shared parent and distinct audience/format objective, preserves factual meaning, rights and required disclosures.

## 4. Studio pipeline

- LLM generates structured draft from evidence, with claim IDs for factual assertions and confidence/uncertainty. Output validated against schema; reject unknown claim IDs and unsupported numbers. Schema repair at most once; then human review. Never treat model text as executable instruction.
- Script segments: hook, context, explanation, example, takeaway/CTA; time estimate from language-specific speaking rate only; actual voice timing overrides. No misleading hook. Long-form has chapter structure and citations; shorts stand alone, no misleading clipping. Optional own-media clipping uses transcript timestamps and preceding/following context, user-owned source only.
- Storyboard scenes carry text, duration, asset references, narration segment IDs, evidence claim refs, visual specification and transitions. Generated asset may be proposed before rights check but cannot be finalized/published with unknown license. Human can adjust script, pronunciation and scene; editing invalidates downstream hashes and review. Scene duration derived from actual audio, captions never exceed scene bounds.
- Language localization: normalize numbers, units, honorifics, local examples, translation glossary and manual review for high-risk topics. Do not change factual values across locales. A translation is a derived revision with distinct narration/metadata and required disclosures.
- Output packages include article/caption text, citations or appropriate references, alternate titles, thumbnails and accessibility alt text. Reviewer checks claim traceability, originality and editorial value at channel level. Automated similarity and factual heuristics are triage only; no automatic guarantee of YPP approval.

## 5. Research integrations

Engram adapter imports/export Markdown with source IDs, timestamps, hash, page coverage and access policy. It does not assume a current private API. Verify actual repository interface and version, use file interchange first. PeerHub adapter submits bounded tasks with expected schema, allowed providers, token/cost limits and correlation ID; results untrusted until validated. Direct LLM/local or deterministic fixture fallback if configured; no silent substitution to paid or remote. Consumer web/CLI subscriptions are not automatically API credits or unattended execution permission. Use supported CLI noninteractive mode under user entitlement, timeout, isolated working directory, no interactive cookie extraction. For web-only tools create manual handoff packet; do not automate login or session hijacking.
